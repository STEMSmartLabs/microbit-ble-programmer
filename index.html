Compatibility and safety notes
  • Bluetooth programming works when the selected MakeCode file matches the software already on the micro:bit.
  • When the app recommends USB, connect the micro:bit with a USB cable and copy the downloaded file to the MICROBIT drive.
  • Keep the micro:bit powered and keep this page open until programming is complete.
  • Use a browser and device that support Web Bluetooth.
